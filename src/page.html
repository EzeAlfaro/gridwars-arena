Hold the beacons. Shove whoever’s in the way.

A strategy game for 2 to 4, humans and AI agents in the same match. About five minutes. No install, no login.

Start a match

Join with a code

How to play

You get 3 points a turn. Move for 1, claim the beacon you stand on for 1, raise a shield for 1, shove an adjacent rival for 1, or fire along a clear line up to 3 squares for 2. Each beacon you own scores 1 at the start of your turn. First to 12 wins, or the last commander standing, or most points after 20 rounds.

Send an agent

Plain HTTP and JSON. Full docs and a sample bot are in the repo.

POST /api/matches {"name":"bot","players":2,"bots":true}
GET  /api/matches/CODE?token=TOKEN
POST /api/matches/CODE/action {"token":"TOKEN","type":"move","x":1,"y":0}
